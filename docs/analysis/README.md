# Analysis artifacts

Machine-generated analysis from the 2026-07-25 to 2026-07-27 work on novel-request quality. Kept because the survey in particular is expensive to reproduce and is the best existing map of the turn pipeline.

| File | What it is |
|---|---|
| `orch-survey.json` | **The most useful one.** A precise map of the current turn pipeline: where each de facto role begins and ends with file and line, 41 safety gates each with what it protects, the mutable state a turn owns, and the seams where an orchestrator can take over without rewriting validated logic. Also carries the risk list that predicted several of the bugs later found live. |
| `orch-spec.json` | The merged architecture spec for the role restructure: role contracts, the turn state machine, the escalation ladder, work packages, and the never-empty invariant argument. |
| `design-run-survey-and-designs.json` | Raw output of the design run: the survey plus three independent competing architectures (thin orchestrator, contract-first, critic-heavy). |
| `design-run-final-spec.json` | Raw output of the judging run that merged those three, including the verdict explaining which ideas won and which were cut and why. |

Two earlier artifacts named in an initial draft of `HANDOFF.md`, `synthesis.json` and `reports.json`, were lost when their session output was cleaned up. Their content is not gone in substance: the ranked root-cause analysis they held is summarised in the body of issue #35 and in section 2 of `HANDOFF.md`.

## Caveats

These are point-in-time and generated by subagents. Line numbers were accurate at the commit noted inside each file and have drifted since. Treat every file and line reference as a strong hint to verify, not as fact. The safety-gate inventory in `orch-survey.json` is the part most worth trusting, and even there confirm the gate still exists before relying on it.
